# HR-Analytics-Dashboard

## 📊 Project Overview

This project is an interactive Tableau dashboard created to analyze
employee data and generate useful HR insights.

## 🛠️ Tools Used

* Tableau
* Excel / CSV
* Data Visualization
* Data Analysis

## 📌 Dashboard Features

* Employee analysis
* Department-wise analysis
* Job role analysis
* Gender-wise analysis
* Age-wise analysis
* Attrition analysis
* Employee satisfaction analysis
* Interactive filters
* Charts and KPIs

## 📂 Files

* `HR_Analytics_Dashboard.twbx` - Tableau packaged workbook
* `Dataset/` - Dataset used for analysis
* `screenshots/` - Dashboard screenshots
